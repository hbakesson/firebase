# High-Density Capacity Planning & Resource Grid Architecture

This report analyzes advanced capacity planning and resource management through integrated timeline grids. By consolidating high-level portfolio forecasting and granular task scheduling into a single visual ecosystem, this new functionality enables professional service firms to manage team utilization, prevent burnout, and protect project margins smoothly.

## 1. The Twin-Grid Paradigm
The architecture breaks resource management into two tightly integrated timeline layers driven by a single source of truth:

*   **The Portfolio Bookings Grid (Macro View):** A high-level capacity heatmap that visualizes entire team or cross-departmental availability across weeks, months, or rolling windows. It shows confirmed bookings alongside pipeline projects to forecast demand.
*   **The Detailed Task Grid (Micro View):** A granular view where specific tasks are assigned to individual days. Changes here ripple up to the Portfolio view instantly, ensuring the heatmap is always based on actual task data.

## 2. Visual Intelligence: The Heatmap Spectrum
To make capacity management intuitive, the system uses a strict, color-coded visual hierarchy within timeline cells:

*   **Optimal Allocation (Green):** Resource is booked within ideal capacity (typically 75-90%).
*   **Buffer/Time-off (Yellow/Gray):** Indicates holidays, sickness, or non-project time.
*   **Full Commitment (Purple):** Resource is exactly at 100% capacity.
*   **Critical Overload (Red):** Resource exceeds 100%, triggering a "Burnout Warning."

## 3. Fluid Resource Rebalancing
The system replaces manual resource rebalancing with flexible interface mechanics:

*   **Drag-and-Drop Reassignment:** Move task blocks between resources or dates without breaking project logic.
*   **Placeholder Roles:** When a project is in the pipeline, managers can book against a **"Placeholder Role"** (e.g., *Senior Developer*). This reserves capacity before specific staff are assigned.
*   **Waiting List (Backlog):** A side panel containing unassigned tasks that can be dragged into the grid as capacity becomes available.

## 4. Algorithmic Distribution Tools
To avoid manual hour-crunching, the grid provides programmatic automation:

*   **Distribute Evenly:** Spreads a task's hours equally across the duration of the project.
*   **Squeeze/Front-load:** Fills the earliest available slots first to complete work as soon as possible.
*   **Role-Based Matching:** Suggests available team members based on the requirements of a placeholder booking.

## 5. Financial & Data Integrity
The planning grid is tied to the company's financial health:

*   **Locking Periods:** Once a month is closed, planning records are locked to prevent historical data corruption.
*   **Actual vs. Budget Variance:** Real-time tracking of how many hours were "Planned" vs. how many were "Reported" (Actuals), visualized directly in the reporting dashboard.
